Projeto Integrador · URI

PassFy

Plataforma web de venda de ingressos para eventos. Organizadoras cadastram eventos com lotes de ingressos, e os clientes buscam eventos, montam o carrinho, finalizam a compra e acessam os ingressos numa carteira digital. O sistema consulta o CEP pela API ViaCEP e atualiza sozinho o status dos eventos encerrados ou esgotados.

  • PHP
  • Laravel
  • Blade
  • Banco de Dados
  • API ViaCEP

Sistema de Gestão Documental Inteligente

Aplicação desktop para prefeituras organizarem seus documentos. Ao enviar um PDF ou imagem, o sistema extrai o texto (com OCR quando necessário) e usa a IA Gemini para identificar o tipo do documento, a secretaria responsável e a data. Tem login, busca, filtros por secretaria, tipo, privacidade e período, e um painel com o total de documentos e o espaço usado.

  • Python
  • CustomTkinter
  • Google Gemini
  • OCR (Tesseract)
  • PyMuPDF

Processamento de Imagens

Editor de Processamento de Imagens

Aplicação web que roda direto no navegador e aplica técnicas clássicas de processamento digital de imagens, todas implementadas do zero, pixel a pixel: operações aritméticas entre imagens, equalização de histograma, limiarização, operações lógicas, filtros de suavização (média, mediana, gaussiano), detecção de bordas (Prewitt, Sobel, Laplaciano) e morfologia matemática (erosão, dilatação, abertura e fechamento).

  • JavaScript
  • Canvas API
  • HTML
  • CSS
